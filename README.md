# Earnings Website with Reward Video Ads

A responsive website where users can watch video ads to earn virtual coins and redeem them for rewards.

## Features

- **Watch & Earn**: Simulated video ads that reward users with coins
- **Reward System**: Virtual coins that can be redeemed for gift cards
- **User Stats**: Track videos watched, coins earned, and daily progress
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Local Storage**: User progress is saved in browser

## How to Use

1. **Watch Videos**: Click the "Watch Video" button to start a simulated ad
2. **Earn Coins**: Complete the 30-second ad to earn 10 coins
3. **Redeem Rewards**: Use your coins to redeem virtual gift cards
4. **Track Progress**: Check your stats on the dashboard

## Setup Instructions

1. Clone or download this repository
2. Open `index.html` in your browser
3. No server required - works locally or on GitHub Pages

## Deploy to GitHub Pages

1. Create a new GitHub repository
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select "main" branch as source
5. Your site will be published at `https://[username].github.io/[repository-name]`
